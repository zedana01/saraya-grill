# مطعم ومشويات السرايا جريل (Saraya Grill) 👑

موقع ويب متكامل وفائق الفخامة لمطعم ومشويات السرايا جريل، مع لوحة تحكم ذكية (CMS) لإدارة الأصناف، الأسعار، المحتوى، والصور.

## 🌟 المميزات الرئيسية
- **تصميم ملكي فاخر:** ألوان الفحم الداكن والذهب الملكي (`#0c090a`, `#d4af37`) متوافق بنسبة 100% مع الهوية الأصلية.
- **قائمة طعام تفاعلية:** 24 صنفاً فاخراً مقسمة إلى 5 تصنيفات (الرئيسية، المقبلات، البيتزا والباستا، الحلويات، والمختارات الملكية).
- **نظام حجز طاولات متكامل:** حجز أونلاين للأجنحة الملكية مع توليد رسائل واتساب مفصلة فورية.
- **لوحة تحكم ذكية للعميل (Admin Dashboard):**
  - تسجيل الدخول برمز PIN (الافتراضي: `1234`).
  - إضافة، تعديل، وحذف الأصناف والأسعار.
  - إمكانية رفع الصور مباشرة من الكمبيوتر أو الجوال (Base64).
  - تعديل نصوص وعناوين كافة صفحات الموقع (Visual CMS).
  - تصدير واستيراد نسخ احتياطية كاملة (JSON Backup & Restore).
- **نظام الطلب والسلة:** سلة منبثقة تفاعلية وحساب إجمالي مع إرسال الطلب المباشر للمطعم عبر واتساب.
- **استضافة سحابية فورية:** مربوط على منصة Cloudflare Pages السريعة.
